### AI와 같이 만든 방식

코드는 대부분 Claude Code와 함께 짰습니다. 제가 한 일은 화면을 직접 써 보면서 어색한 곳을 찾고, 어떻게 바뀌어야 하는지 AI에게 설명하고, 결과가 맞는지 확인하는 것이었습니다. 마음에 안 들면 되돌리고 다시 요청했습니다.

| 화면에서 발견한 문제 | 요청한 방향 |
|---|---|
| 캐릭터 크기가 화면마다 다르고 얼굴이 잘려 보임 | 모든 화면에서 캐릭터 눈높이와 크기를 맞추기 |
| 단계가 많아 복잡하다는 피드백 | 온보딩 6 → 5단계, 리포트 탭 5 → 4개로 줄이기 |
| PIN을 잘못 입력해도 어디가 틀렸는지 모름 | 오류 문구를 틀린 입력칸 바로 옆에 띄우기 |

AI에게 맡기더라도 원하는 걸 정확히 설명하고 결과를 판단하는 건 제 몫이라는 걸 느꼈습니다. 그래서 지금은 기초부터 다시 공부하고 있습니다.
